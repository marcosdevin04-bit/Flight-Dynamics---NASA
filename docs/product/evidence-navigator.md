# Evidence navigator and 3D scenarios
Open **Similar tests** to compare a query with the two team JSON files. An exact match applies only to the fields supplied and the cited protocol. A related result lists differences or missing fields. If the strict query finds nothing, the navigator looks for same-material background observations, including LUCI and the habitat-pressure study. Absence means no comparable entry in this catalogue, not that NASA never conducted the experiment.

**Adapt this scenario** transfers the engineer’s conditions. **Start from [record]** transfers reported fields from the reference first and preserves or defaults missing values. The chamber displays its starting reference, and changing controls reruns the search. Measured oxygen limits, LUCI flame-spread observations and summarized habitat tests are different kinds of evidence.

The live, optional on-device AI selects among existing citation IDs after retrieval. An unknown ID is rejected; displayed facts always come from the records. Browsers without a ready model retain deterministic guidance. The SIBAL demo has a cached AI interpretation.

**Material and oxidizer are distinct.** The illustrative chamber uses a normalized sheet, rod or pool source. A generic hydraulic fluid and unspecified spacecraft fuel both use the pool geometry, deliberately with the same kinetics: no data establish their formulations. Controls change ambient oxygen or select an inert, air-like or oxygen-enriched preset. This is a simplified oxygen-based model, not a simulation of liquid propellants, alternate oxidizer chemistry or spacecraft propulsion.
